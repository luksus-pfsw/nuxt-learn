## 🚀 QUICK START

### 1. Środowisko (30 min)
```bash
# Sklonuj repo, zainstaluj Docker + Java21 + Node20
git clone <repo-url> && cd nuxt-learn

# Uruchom infrastrukturę
cd docker && docker-compose up -d

# Uruchom backend + frontend
cd ../backend && ./mvnw spring-boot:run  # Terminal 1
cd ../frontend && npm install && npm run dev  # Terminal 2
```

### 2. Rozpocznij Naukę

**Scenariusz A: Pełna ścieżka (0 → 100%)**
